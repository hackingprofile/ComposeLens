# Maintainers

ComposeLens is maintained by the people with write access to this GitHub repository; the repository's **People** and **Contributors** pages show who they are.

| Need | Where |
| --- | --- |
| Questions, bugs, feature requests | GitHub issues (`SUPPORT.md`) |
| Security problems | GitHub private vulnerability reporting, from the repository's **Security** tab (`SECURITY.md`) |
| Contributions | Pull requests against `main` (`CONTRIBUTING.md`) |

Repository access determines ownership; `CODEOWNERS` defines no per-path owners.
